# Schede dei lavori grossi (D346)

Una scheda per ogni lavoro grosso: una funzione nuova del sito o del motore, una fonte nuova, un lavoro di più giorni. Mezza pagina, in italiano, mostrata a Oscar prima di scrivere codice. Nome del file: `AAAA-MM-<nome>.md`.

```
# <Titolo>
Stato: proposta | approvata | in corso | finita (data)

## Perché
Una o due frasi: il problema, con le parole di Oscar se ci sono.

## Cosa deve fare
- ...

## Cosa non fa
- ...

## Finito quando
- [ ] condizioni verificabili, una per riga

## Decisioni da Oscar
- ...

## Verifica (a lavoro chiuso)
Per ogni riga di "Finito quando": come è stata controllata e il risultato.
```

Le regole restano dove sono: pilastri in PILLARS, decisioni in DECISIONS, metodo in METHOD, criteri di prova in BACKTEST_PROTOCOL. La scheda li cita, non li ripete.
